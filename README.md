Live: https://samgestudio-dev.github.io/Perasure/

| Demo | Path |
| --- | --- |
| Withdraw fund flow | `demos/withdraw-fund-flow/` (standard) · `demos/withdraw-fund-flow/with-blur.html` (with gradient blur) |

## Adding a demo

1. Put the demo's files in `demos/<slug>/`. The main file should be `index.html`.
2. Add one entry to the `DEMOS` list in the root `index.html`, with a title, short description and one or more variants. The first variant is the recommended one.

Each demo is a single self-contained HTML file, so there is nothing to build.
