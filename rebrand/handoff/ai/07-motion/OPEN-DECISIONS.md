# 07-motion — open decisions for the owner

Ten questions the motion hand-off could not settle alone. For each: what the package does now, the alternative, and the flag or file to change. Paths and line numbers are in the visual + motion tree (`0d9bdd4` + `tools/apply.py --step all` + `npm install motion@14.4.0` + `07-motion/motion.patch`; step 8 does not move these lines). Decided items are in `README.md` → "Decisions".
