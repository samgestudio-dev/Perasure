# Reviews

Dated audits of the app and the shared components (performance, accessibility, design engineering…), one file each:
`YYYY-MM-DD-<kind>.md` (for example `2026-11-20-audit-as-perf-eng.md`).

Each review lists what was checked, the findings ranked by severity, and what was fixed (with commit ids). A finding that turns into a rule
gets a [decision record](../docs/decisions/README.md); a change it causes gets a [CHANGELOG](../CHANGELOG.md) line.
